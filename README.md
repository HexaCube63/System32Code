# System32 — Modern Cyber Safety & AI Risks

**System32** is a multi-page informational web project dedicated to demystifying modern cybersecurity fundamentals and exploring the evolving threat landscape of Generative AI. Built from the ground up using strict, syllabus-compliant HTML and CSS, the platform provides structured educational resources, comparative risk analyses, and practical digital defense protocols.

---

## 📌 Project Overview

As artificial intelligence reshapes the digital landscape, traditional cyber threats have evolved into automated, hyper-personalized attack vectors. **System32** bridges the gap between foundational internet hygiene and modern AI literacy—helping everyday users understand how generative models operate, how attackers exploit them, and what steps individuals can take to secure their digital identities.

### Core Objectives
* **Accessible Education:** Break down complex cybersecurity and machine learning concepts into clear, structured, and easy-to-digest modules.
* **Comparative Threat Awareness:** Contrast traditional cyber risks (e.g., generic phishing, basic dictionary attacks) against modern AI-driven equivalents (e.g., real-time voice cloning, spear-phishing, polymorphic malware).
* **Syllabus-Compliant Architecture:** Demonstrate clean, semantic web design and structured multi-page navigation using foundational HTML and CSS without relying on external frameworks or heavy scripts.

---

## 🗂️ Site Architecture

The website is organized as a connected collection of modular web pages:

* **`index.html` — Home & Overview Gateway**
  * Features the project hero banner, system status readout, quick-navigation directory cards, and an **Old Risks vs. New Risks** comparative matrix.
* **`cybersafety.html` — Cyber Safety Fundamentals**
  * Covers core digital hygiene, credential management, encryption basics, and protecting personal data footprints.
* **`threats` — Threat Intelligence Matrix**
  * A structured breakdown of active cyber threats, social engineering tactics, risk severity indicators, and real-world attack scenarios.
* **`responsibilities` — Digital Citizenship & Ethics**
  * Outlines user accountability online, including consent, misinformation prevention, and responsible reporting.
* **`safe` — Defensive Protocols & Countermeasures**
  * Actionable checklists and step-by-step habits for hardening accounts, verifying communications, and maintaining device security.
* **`ai.html` — Generative AI & Emerging Risks**
  * Explains the mechanics behind pattern-predicting AI models alongside deepfake spoofing, automated scams, data scraping, and AI safety guardrails.

## 🛠️ Technical Stack & Design Constraints

* **Languages:** Pure HTML5 & CSS3
* **Layout & Styling:** 
  * Custom dark-mode interface featuring a high-contrast slate palette (`#0f172a`), cyan accents (`#38bdf8`), and purple-to-cyan gradient banners.
  * Table-based structural containers and card grids engineered for clean alignment and strict compliance with foundational HTML/CSS syllabus standards.
* **Version Control & Deployment:** Hosted via GitHub and deployed continuously to Netlify.
